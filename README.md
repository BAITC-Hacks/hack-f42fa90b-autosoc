# Умный подбор подрядчиков

Сервис для подбора подрядчиков и площадок под параметры мероприятия в рамках задачи HackAlem AI «Умный подбор подрядчиков» (#79-lite). Пользователь задаёт город, дату, формат, категорию и бюджет, а сервис должен вернуть до трёх подходящих вариантов с краткими, проверяемыми объяснениями.

## Текущий статус

Подготовлены требования и архитектура, реализация впереди. В репозитории пока нет работающего backend, frontend и команд запуска. Наличие этих документов само по себе не означает прохождение проверки организаторов.

Исходный файл `data/hackathon-dataset-anonymized.jsonl` на момент подготовки этапа отсутствует. Он не заменён тестовыми или вымышленными данными.

## Планируемый стек

- Python;
- FastAPI;
- статический HTML/CSS/JavaScript, отдаваемый тем же сервером;
- тесты для правил фильтрации, ранжирования и API.

## Последовательность этапов

1. Зафиксировать требования, ограничения и архитектуру.
2. Получить и проверить исходный датасет, не изменяя его.
3. Реализовать загрузку данных, схемы и валидацию входа.
4. Реализовать детерминированные фильтрацию и ранжирование.
5. Добавить объяснения на основе проверенных фактов и шаблонный fallback без AI API.
6. Реализовать API и минимальный статический интерфейс.
7. Покрыть ключевые сценарии тестами и проверить чистый запуск по README.
8. Подготовить и проверить демонстрационные сценарии.

Команды установки и запуска будут добавлены только вместе с работающей реализацией. Финальная версия должна запускаться по README без личного аккаунта участника.

## Рабочие ограничения

- Фактический прогресс необходимо фиксировать за каждый час; планы нельзя выдавать за реализованный функционал.
- Основная работа ведётся только в выданном командном репозитории.
- Срок финальной версии — **23.09.2026, 18:00 по времени Астаны**.
- Чистый запуск по README не должен зависеть от личного аккаунта участника.
