# Правила работы с проектом

- Не изменяйте исходный датасет `data/hackathon-dataset-anonymized.jsonl`.
- Не выдумывайте свойства подрядчиков и площадок: используйте только подтверждённые поля исходных данных и результаты детерминированных правил.
- Не храните секреты, токены, пароли и реальные ключи API в Git.
- Проверяйте реализованную функциональность автоматическими тестами, включая граничные и отрицательные сценарии.
- Документируйте только реально сделанное; планы и предлагаемую архитектуру явно отделяйте от реализации.
- Раскрывайте использованные сторонние компоненты, их назначение и необходимые лицензии.
- Сохраняйте возможность чистого запуска по README без личного аккаунта участника.
